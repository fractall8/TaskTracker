- (decision) [ADOPTED] Paradigm: Clean Architecture + CQRS (MediatR). Dependency direction one-way: Presentation -> Infrastructure/Persistence -> Application -> Domain. Domain has zero deps; Application depends only on Domain + Shared/Contracts. Binds: all backend layers. Prevents: circular/upward references, business logic leaking into Presentation.
- (decision) [ADOPTED] Shared/Contracts is the sole source of truth for wire shapes (DTOs, requests, SignalR notification payloads) consumed by both Backend and Frontend. Prevents: each side inventing its own shape for the same wire data.
- (decision) [ADOPTED] Plan/feature entitlement gating is enforced end-to-end via IRequireWorkspaceFeature + WorkspaceFeatureGuardBehavior (backend, throws SubscriptionFeatureRequiredException) mirrored by WorkspaceSubscriptionsStore (frontend, visual-only gating). Prevents: a gated feature enforced on only one side.
- (decision) [ADOPTED] DB schema authority is DbUp numbered SQL scripts (Database/Scripts/000N_*.sql); EF Core Configurations mirror schema for querying but never generate/apply it. Prevents: EF migrations and DbUp scripts drifting into two competing schema authorities.
- (decision) [ADOPTED] Error contract: backend throws Domain.Exceptions.AppException subtypes (StatusCode+Title), GlobalExceptionHandler renders ProblemDetails; frontend HandleResponseAsync extracts message from ProblemDetails.Errors/Detail/Title and throws untyped Exception. Prevents: ad hoc error shapes per endpoint.
